# Product Plan: Daily Organizer AI dApp

## Product vision
Build a personal operating system that helps users capture information, structure knowledge, plan goals, and execute daily with AI guidance.

## Core modules
1. **Execution:** Tasks, priorities, daily planning.
2. **Knowledge base:** Notes, source links, mind maps.
3. **Knowledge graph:** ConceptLink relationships between ideas.
4. **Search/query:** One query endpoint for notes/tasks/goals.
5. **Insight engine:** Daily + weekly insights, progress reports, advice.
6. **Goal planning:** Short and long-term plans with milestone tracking.
7. **Decentralized proof:** Hash important summaries on-chain.

## Insight outputs
- Daily insights: completion, load level, top focus category.
- Weekly insights: trend and sustained productivity view.
- Progress report: aggregate goal progress.
- Advice: concrete next steps for today and this week.
- Planning suggestions: short-term sprint plan and long-term roadmap direction.

## Information structuring workflow
1. Capture notes quickly with tags.
2. Attach source links and context.
3. Link concepts into relationship edges.
4. Roll up concepts into mind maps.
5. Connect concepts/notes to goals.
6. Use AI to propose refinements and focus actions.

## Multi-platform publishing
- Web app (primary)
- Google extension (quick-capture and sidebar assistant)
- Android app (mobile capture + insights)
